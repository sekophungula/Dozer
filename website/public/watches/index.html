What it watches

Everything that keeps your Mac awake

Dozer watches four kinds of work. Each counts only while it's actually working, so nothing sitting idle keeps your Mac up. Turn any of them off from the menu bar.

Apps

Count while they're exporting, rendering or building, after about 15 seconds of hard work, including the helper processes they start. Watched when installed, and you can add any other app. How app watching works →

Downloads & uploads

Count while 250 KB/s or more keeps moving in either direction for about 15 seconds, whichever app is doing it. Music and messages are too light to count. Downloads & uploads →

Safari · Chrome · Firefox downloadsYouTube · Vimeo uploadsDropbox · WeTransfer iCloud Drive · Google Drive · OneDrive syncOnline backupsDownload managersGame & macOS installers

Terminal commands & CLI agents

A command counts for as long as it runs. Agents, editors and REPLs count only while they keep working. Works in Terminal, iTerm, Ghostty, Warp, VS Code and tmux. Terminal & CLI agents →

Claude Code

Connects through hooks, so Dozer knows the moment a task starts and the moment Claude stops. Works in the CLI and the Code tab of the Claude desktop app. Claude Code →
