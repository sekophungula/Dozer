Install

Three steps the first time.

  1. 1

    Open the disk image and drag

    Open Dozex.dmg and drag Dozex onto the Applications folder beside it.

  2. 2

    Allow it once in System Settings

    Dozex isn't notarised by Apple yet, so the first time macOS says “Dozex” Not Opened. Click Done, open System Settings → Privacy & Security, scroll down to Security and click Open Anyway next to Dozex, then confirm. After that it opens normally. Step by step →

  3. 3

    Pick what to watch

    The setup page lists the export and render apps on your Mac, already switched on. Using Claude Code? Click Connect Claude Code too. Then look for the eye in your menu bar. Full install guide →
