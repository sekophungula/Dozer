“Dozer” Not Opened

Dozer isn't notarised by Apple yet, so macOS blocks the first launch. It isn't malware, and you only need to allow it once:

  1. Click Done in the warning. Don't click Move to Bin.
  2. Open System Settings and go to Privacy & Security.
  3. Scroll down to the Security section. You'll see “Dozer was blocked to protect your Mac.”
  4. Click Open Anyway, confirm with your password or Touch ID, then click Open Anyway in the next dialog.

The Open Anyway button only shows for about an hour after the warning. If it's gone, open Dozer again to bring it back. Or in Terminal:

xattr -dr com.apple.quarantine /Applications/Dozer.app

My Mac still slept during an export

  • Check Watch apps is on, and the app is set to When busy or While open on the setup page.
  • Did the lid close? A MacBook always sleeps with its lid closed unless an external display is connected.
  • If the export barely uses the CPU, set the app to While open.
  • Not listed? Add it with Add an app….

It says something is working when nothing is

Open the menu bar panel: the line under the title says what's being counted. A forgotten terminal command, a cloud folder syncing, or an app set to While open are the usual reasons. Turn off the matching switch, or stop the job.

My Mac never sleeps

  • Make sure Keep awake indefinitely is off.
  • Check for apps set to While open.
  • Other apps can also keep a Mac awake. Run pmset -g assertions in Terminal to see who's holding it. Dozer's entries start with “Dozer:”.

Claude Code isn't picked up

Check Connect Claude Code shows Connected on the setup page. Sessions that were already open pick it up on their next prompt.
