Requirements

  • Xcode 26 or later (for the Control Center extension SDK). No Xcode project is needed.

Build

Clonegit clone {{REPO}} && cd Dozex
BuildScripts/build.sh
PackageScripts/build.sh --package

Scripts/build.sh writes a universal build/Dozex.app. With --package it also makes Dozex.zip and Dozex.dmg.

Options

VariableUse
VERSION=1.5.0Stamp a version number.
BUILD_NUMBER=8Stamp a build number.
SIGN_IDENTITY="Developer ID Application: …"Sign with your own certificate instead of ad-hoc.

The website

This site is built from fragments in website/src:

python3 website/build.py
