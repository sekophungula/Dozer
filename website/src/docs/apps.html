Long exports and renders are the main reason a Mac falls asleep at the wrong moment. Dozer watches the apps that do them and keeps your Mac awake while they're working, then lets it sleep when they finish.

When busy, while open, or off

Each app has a setting on the setup page:

  • When busy (the default): counts while the app is working hard. Opening a project, scrolling the timeline or leaving the app open doesn't count.
  • While open: keeps your Mac awake the whole time the app is open, busy or not. Useful for a media player, a remote-desktop app or a long-running tool that doesn't use much CPU.
  • Off: ignore the app.

What “busy” means

Dozer checks every 3 seconds how much CPU the app is using, including any helper processes it started, such as render workers or encoders. When it uses 10% or more for most of about 15 seconds, it counts as busy. It stays busy until it has gone quiet for about 12 seconds, so short pauses in an export don't let the Mac sleep.

An app with a project open usually sits well under 10%. An export or render uses far more.

Add any app

On the setup page, click Add an app… and choose it from Applications. It's added as When busy; change it to While open if that suits it better. Remove an added app with the minus button next to it.

Example: exporting from Final Cut Pro

  1. Start the export with File → Share as usual.
  2. After about 15 seconds the eye opens and the menu says Final Cut Pro is working.
  3. Walk away. The screen may turn off, but the Mac stays awake and the export keeps going.
  4. When the export ends, Dozer waits for the grace period, then lets the Mac sleep. You'll get an All done notification.

If an export uses very little CPU (for example it runs mostly on the graphics chip) and Dozer doesn't pick it up, set the app to While open.
