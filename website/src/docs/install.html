Requirements

  • macOS 14 Sonoma or later, on Apple Silicon or Intel.
  • macOS 26 for the optional Control Center toggle.

Download and open

  1. Download Dozer.dmg and open it.
  2. Drag Dozer onto the Applications folder in the window that opens, then eject the disk image.
  3. Open Dozer from Applications. It isn't notarised by Apple yet, so the first time macOS shows “Dozer” Not Opened. Click Done (not Move to Bin).
  4. Open System Settings → Privacy & Security, scroll down to Security, and click Open Anyway next to “Dozer was blocked…”. Confirm with your password or Touch ID, then click Open Anyway again.

You only do this once. Updates install themselves and open normally.

Or in Terminalxattr -dr com.apple.quarantine /Applications/Dozer.app

Set it up

The setup page opens on first launch. You can reopen it any time with Setup… in the menu bar panel, or by opening Dozer from Applications again.

  1. Pick the apps to watch. Export and render apps found on your Mac are listed and already switched on. Add others with Add an app…. See Apps.
  2. Choose how Dozer behaves. Downloads, terminal watching, the display and notifications. See Settings.
  3. Connect Claude Code if you use it. See Claude Code.
  4. Open at login so it's always running. See Control Center & login.

Dozer has no Dock icon. Look for the eye in your menu bar.
