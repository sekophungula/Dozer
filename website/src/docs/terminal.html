Dozex looks at every terminal tab, in Terminal, iTerm, Ghostty, Warp, VS Code's terminal and tmux panes, and checks what's running in front.

Commands

A regular command, like npm run build, cargo test, rsync or a script, keeps your Mac awake for as long as it runs. When you're back at the shell prompt, it no longer counts.

CLI agents

Agents sit open for hours while idle, so they count only while they keep working: 3% CPU or more for most of about 15 seconds. Known agents include:

Claude Code, Codex, Gemini CLI, Aider, OpenCode, Cursor Agent, Amp, Goose, Qwen Code, Crush, Droid, Copilot CLI, Kiro, Cline, Continue, Plandex and OpenHands.

An agent waiting at its prompt lets your Mac sleep. A quick spike, like an idle agent redrawing its screen, doesn't count.

Editors, ssh and REPLs

Vim, Neovim, Emacs, less, top, ssh, tmux, database shells and language REPLs are treated the same way as agents: they count only while they keep using CPU.

Turn terminal watching off with Watch Terminal in the menu bar panel.
