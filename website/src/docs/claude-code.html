Claude Code tells Dozex exactly when a task starts and when Claude stops, through hooks. That's more precise than watching CPU, because Claude can spend a while waiting on a reply while barely using the CPU.

Connect

On the setup page, click Connect Claude Code. Dozex adds hooks to ~/.claude/settings.json:

HookWhat it does
UserPromptSubmit, PreToolUse, PostToolUseMarks the session as working.
Stop, SessionEndMarks the session as done.

Your existing settings are kept, and a copy is saved as ~/.claude/settings.json.sleepable-backup first. It works for the Claude Code CLI and for the Code tab in the Claude desktop app.

Sessions that were already running

Sessions started before you connected pick up the hooks on their next prompt. Until then, Dozex falls back to watching claude processes that keep using CPU.

Disconnect

Click Disconnect on the setup page to remove the hooks.
