Dozer checks GitHub for new versions automatically. When one is out, the menu bar panel shows Dozer x.y.z is available with an Update button.

How an update installs

  1. Click Update. Dozer downloads the new version from GitHub Releases.
  2. It replaces itself in place, wherever it lives, and reopens.
  3. Your settings, watched apps and Claude Code connection carry over.

Turn off automatic checks

Switch off Check for updates automatically on the setup page. You can still check any time with Check for Updates in the menu bar panel.

See what's new in the changelog.

Coming from Dozex or Sleepable

Dozer used to be called Dozex (versions 1.2.0 to 1.5.0) and, before that, Sleepable. Click Update in the old app as usual: it installs the new version, which renames itself to Dozer on its first launch. Your settings, watched apps, Claude Code connection and login item all carry over.
