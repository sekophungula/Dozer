Dozex checks GitHub for new versions automatically. When one is out, the menu bar panel shows Dozex x.y.z is available with an Update button.

How an update installs

  1. Click Update. Dozex downloads the new version from GitHub Releases.
  2. It replaces itself in place, wherever it lives, and reopens.
  3. Your settings, watched apps and Claude Code connection carry over.

Turn off automatic checks

Switch off Check for updates automatically on the setup page. You can still check any time with Check for Updates in the menu bar panel.
