Dozex

Your Mac stays awake while Claude works, then sleeps as soon as every task is done.

Download for macOS View source on GitHub

Free and open source · macOS 14 Sonoma or later · Apple Silicon & Intel

What it does

👁️ Awake while Claude works

Long Claude Code runs don't stall because your Mac dozed off. Dozex holds a power assertion only while a task is in flight.

🌙 Sleeps when it's done

When the last Claude task finishes (plus a short grace period), Dozex lets go and your normal Energy settings take over.

🎚️ One-click toggle

Turn it on or off from the menu bar, or add the Dozex control to Control Center on macOS 26 and later.

🔔 Tells you when it's done

An optional notification lets you know Claude has finished and the Mac can rest.

Install

  1. Download Dozex.dmg and drag Dozex into Applications.
  2. Open it. Dozex isn't notarized by Apple yet, so the first time macOS will block it. Go to System Settings → Privacy & Security, scroll down and click Open Anyway. Or run: 
    xattr -dr com.apple.quarantine /Applications/Dozex.app
  3. The setup page opens. Click Connect Claude Code so Dozex knows exactly when tasks start and stop.
  4. Look for the eye icon in your menu bar. Optionally add the Dozex control in Control Center → Edit Controls.

How it knows Claude is working

Claude Code hooks

Dozex adds hooks to ~/.claude/settings.json. A prompt marks a session busy and Stop marks it finished. Your existing settings are kept and backed up first.

Process fallback

Any claude CLI process using CPU also counts as work, which covers sessions that started before you connected the hooks.

Heads-up: closing a MacBook lid without an external display always puts the Mac to sleep. No app can prevent that without admin changes, so keep the lid open for long runs.
