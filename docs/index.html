Stays awake while Claude works

Your energy settings still apply. Dozex only holds off sleep while Claude is actually doing something.

Step 1

You start a task

Prompt Claude, kick off a build, or run Codex or Gemini in your terminal. Dozex notices right away.

Step 2

Your Mac stays up

The menu bar eye opens while the work runs, so long builds and refactors finish without the Mac falling asleep.

Step 3

It dozes off when done

When the last task finishes, Dozex steps aside and your Mac sleeps on its usual schedule.

Small, quiet and precise

No windows to manage and no settings to tune. It sits in your menu bar.

Connects to Claude Code

Lightweight Claude Code hooks tell Dozex exactly when a task starts and stops. Your existing settings are backed up first.

Sleeps as soon as it can

There's no fixed timer. When the work is done, so is Dozex, and you can get a notification to say so.

Menu bar and Control Center

Turn it on or off with one click, or add the Dozex control to Control Center on macOS 26.

Watches your terminal too

Builds, scripts and CLI agents like Codex, Gemini and Aider keep your Mac awake in any terminal app. Idle agents, editors and ssh sessions don't.

Updates itself

New versions install in place with one click from the menu bar. You don't need to download them again.

Private and open source

Everything runs on your Mac. No accounts and no analytics, and the code is on GitHub under the MIT license.

Set up in a minute

Dozex is a small download that works on Apple Silicon and Intel Macs running macOS 14 or later.

Download Dozex.dmg
  1. Drag Dozex into ApplicationsOpen the downloaded disk image and drag the app across.
  2. Allow it to openDozex isn't notarized by Apple yet. The first time you open it, go to System Settings → Privacy & Security and click Open Anyway, or run:
    xattr -dr com.apple.quarantine /Applications/Dozex.app
  3. Connect Claude CodeClick Connect Claude Code on the setup page. That's it. Look for the eye in your menu bar.

Questions

Does it work with the Claude desktop app?

Yes. Dozex works with the Claude Code CLI and with the Code tab in the Claude desktop app. Both use the same Claude Code hooks.

Does it work with Codex, Gemini CLI or other agents?

Yes. Dozex watches every terminal window and tab, including Terminal, iTerm, Ghostty, Warp, VS Code and tmux panes. A command that's running keeps your Mac awake. Agents such as Codex, Gemini CLI, Aider and OpenCode count only while they're working, so a session left open at the prompt won't stop your Mac from sleeping. You can turn this off with Watch Terminal in the menu.

What happens if I close my MacBook's lid?

macOS always sleeps when the lid closes without an external display, and no app can override that without admin changes. Keep the lid open for long runs, or use an external display.

What does it change on my Mac?

It adds a few hooks to ~/.claude/settings.json, after backing up the original. Disconnecting from the setup page removes them again. To keep the Mac awake it uses a standard macOS power assertion, the same one apps use to stop the screen sleeping during video.

What if a session started before I installed Dozex?

Dozex also treats any busy claude process as work, so sessions that are already running are covered until their next prompt picks up the hooks.

Is it free?

Yes. Dozex is free and open source under the MIT license.
